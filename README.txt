Drawing Revision Comparison - local app
=======================================
Works fully offline. No installation, no database, no internet needed.

HOW TO RUN
  Option 1 (simplest): double-click index.html (opens in Chrome / Edge / Firefox).
  Option 2: double-click start.bat (Windows) or run ./start.sh (Mac/Linux).
            This needs Python and opens http://localhost:8080

HOW TO USE
  1. Choose the Rev 1 PDF and the Rev 2 PDF.
  2. Click "Compare & generate report".
  3. Click "Print / Save as PDF" (or Ctrl+P) and choose "Save as PDF".
     Tip: in the print dialog set Layout = Landscape, and enable "Background graphics".

NOTES
  - Both drawings should have the same sheet size and orientation.
  - Files are processed in the browser only; nothing is uploaded or stored.
  - Includes pdf.js 3.11.174 (Apache-2.0) in the libs folder.
